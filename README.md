# رِفاق

تطبيق لمجموعة صغيرة في أي مكان: خريطة العالم أولاً، وسهم يوجّهك نحو الشخص مع المسافة. داخل المسجد الحرام يمكن التبديل إلى مخطط الحرم المحفوظ في الجهاز. الدقة المستهدفة ٥–١٠ أمتار، وهامش الخطأ ظاهر.

يعمل كتطبيق ويب يُثبَّت على أندرويد من Chrome، وعلى الآيفون من Safari عبر «إضافة إلى الشاشة الرئيسية». الموقع والبوصلة والخطوات وإبقاء الشاشة تعمل والتطبيق مفتوح.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح [http://127.0.0.1:47231](http://127.0.0.1:47231).

```bash
npm test
npm run lint
```

## ماذا يفعل

1. شخص ينشئ مجموعة ويشارك رمزاً من ستة أحرف. الباقون يدخلون بالرمز، بلا حسابات.
2. مع الإنترنت يرسل كل هاتف موقعه كل ثانيتين، ويصل فوراً للبقية.
3. الموقع لا يُرسم خاماً: يُصفّى الاهتزاز، وتُرفض القفزات البعيدة، ولا تُعرض نقطة أدق من ±٥ م.
4. إذا ضعف GPS داخل الأروقة تكمل الخطوات والبوصلة الحركة لفترة قصيرة، ويزداد هامش الخطأ مع الوقت.
5. إذا انقطع الإنترنت تبقى آخر خريطة ظاهرة، ومخطط الحرم يعمل دون شبكة. الآخرون يبقون على آخر موقع وصل، مع عمر التحديث.
6. اضغط شخصاً في المجموعة لتفتح نافذة البحث: سهم نحو مكانه والمسافة.
7. الدور داخل الحرم يختاره الشخص. اقتراح تغيير الدور لا يظهر إلا إذا كان قياس الارتفاع نفسه دقيقاً.

المشهد التجريبي على الخريطة مسار للمعاينة فقط، ولا يُرسَل إلى المجموعة.

## التثبيت

- **أندرويد:** من Chrome، «تثبيت التطبيق».
- **الآيفون:** Safari → مشاركة → إضافة إلى الشاشة الرئيسية، ثم السماح بالموقع وحركة الجهاز.

التتبع يعمل والتطبيق في المقدمة. الجوال يوقف الموقع عندما تُغلق شاشة تطبيق مثبت من المتصفح، والتطبيق يقول ذلك بدلاً من ادعاء تتبع في الخلفية.

## الخريطة

حدود المسجد، الكعبة، الحجر، المقام، المسعى، والصفا والمروة، وأبواب رئيسية، من بيانات OpenStreetMap. الخريطة مرسومة داخل التطبيق وتعمل دون شبكة.

## حدود صادقة

GPS داخل الحرم يتراوح غالباً بين عدة أمتار وأكثر. بلوتوث وقوة الإشارة ليسا مسافة. لا توجد بنية UWB ثابتة في هذا الإصدار، ولذلك لا نعد بدقة أقل من متر. مجموعة من ثلاثة هواتف مختلفة تكفي لهذا الهدف عندما تكون السماء أو الساحة مفتوحة، وتضعف داخل الكتلة المبنية.
